# ORM : Object-Relational-Mapping
- 객체(Object)와 데이터 를 매핑(Mapping)하는 기술
- Django는 파이썬언어사용 but 데이터베이스는 SQL을 사용함.
- ORM은 두개 사이의 번역자
- ORM은 Django 개발자를 위해 'QuerySet API'라는 특별한 도구 제공
- QuerySet API는 ORM으 ㅣ기능을 개발자가 파이썬코드 안에서 객체 지향적이고 직관적인 방식으로 데이터베이스를 조작할 수 있도록 제공하는 인터페이스
## QuerySet API
- 개발자는 SQL을 직접 작성하지 않고도, 파이썬다운 메서드를 사용하여 원하는 데이터를 손쉽게 생성,조회,수정,삭제 할 수 있다.
- Article.objects.all()
- 모델클래스,매니저,QuerySetAPI메서드
- QuerySet API와 ORM의 동작 방식 예시
  - django      (QuerySetAPI)=>       ORM         (SQL)=>      DATABASE
  - django (QuerySet or Instance)<=       ORM(SQL)    <=      DATABASE
- Query란?
  - 데이터베이스에 특정한 데이터를 보여달라는 요청
  - 쿼리문을 작성한다 = 데이터베이스에 요청보낼 코드를 작성한다
- QuerySet이란?
  - 데이터베이스에서 전달받은 객체 목록(데이터 모음)
  - Django ORM을 통해 만들어진 자료형
  - 순회가능한 데이터로 1개 이상 데이터를 불러와 사용가능하나,
  - 데이터베이스가 단일객체를 반환할 때는 QuerySet이 아닌 모델(Class)의 인스턴스로 반환됨
- CRUD란?
  - Create(생성), Read(조회), Update(수정), Delete(삭제)
## Create
- Django Shell
  - Django 프로젝트의 코드를 명령창에서 바로 실행하고 테스트하는 특별한 파이썬 환경,  Django 환경 내에서 실행되기 때문에 입력하는 QuerySet API 구문이 Django 프로젝트에 영향을 미침
- 데이터 객체를 만드는 3가지 방법
  - 1. 빈 객체 생성 후 할당 및 저장
  - 2. 초기 값과 함께 객체 생성 및 저장
  - 3. create() 메서드로 한 번에 생성 및 저장(QuerySet API)
- 1번방법 순서:
  - pip install ipython
  - python manage.py makemigrations
  - python manage.py migrate
  - python manage.py shell => from articles.models import Article => Article.objects.all()
  - (python manage.py shell -v 2 => 자동임포트?)
  - article = Article() (Article클래스의 인스턴스변수 article생성)
  - article.title = 'first'
  - article.content = 'django!'
  - article.title
  - article.save()
  - article (소괄호안에 1뜨면 DB에 저장된것)
  - db.sqlite3 파일에서 생성됐는지 확인
- 2번방법 순서:
  - 위에꺼 똑같이하고, 
  - article2 = Article(title='second', content = 'django!')
  - 뒤에똑같음
- 3번방법 순서
  - Article.objects.create(title='third', content='django!')
## Read
- QuerySet 반환 메서드: all()
  - 전체 데이터 조회
- filter()
  - 주어진 매개변수와 일치하는 객체를 포함하는 QuerySet 반환
- QuerySet을 반환하지 않는 메서드: get()
  - 딱 1개만 있을때 사용가능 => 없거나 2개이상이면 에러 => 그래서 QuerySet을 반환하는게 아니라 인스턴스를 반환하는 것 같음.
- 예시:
  - Article.objects.all()
  - Article.objects.filter(content='django!')
  - Article.objects.filter(title='abc')
  - 위에 두개는 쿼리셋을 반환
  - Article.objects.get(pk=1)
  - Article.objects.get(pk=100)
  - 하지만 get은 인스턴스(단1개)를 반환.
## Update
- 데이터 수정 방법
  - 인스턴스 변수를 변경 후 save 메서드 호출
    - article = Article.objects.get(pk=1)
    - article.title = 'byebye'
    - article.save()
## Delete
- article = Article.objects.get(pk=1)
- article.delete()
