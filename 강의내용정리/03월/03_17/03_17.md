0. 학습 시작
- 지도학습: 처음보는 문제도 잘 푸는 AI만들기
  - 예시1 ) 기존 고객 정보 + 탈퇴여부 -> 내일 이탈할 고객 예측
  - 예시2 ) 기존 거래 사기 데이터로 새로운 사기 탐지

1-1 지도학습이란?
고양이에 대해 학습됐다면, 처음보는 고양이사진도 고양이로 라벨붙임.

1-2 지도학습의 종류 (회귀와 분류)
- 회귀
  - 예측하고 싶은 결과값이 숫자일 때 사용
  - 가격,점수,온도 등
- 분류
  - 예측값이 범주일때 사용
  - 스팸/정상 , 질병 유/무

1-3 지도학습 용어
특성(Feature, x)
- 예측에 사용되는 설명 변수
- 집값 예측에서의 feature(지역,평수,방수,연식)
- 이메일 스팸 필터링 에서의 feature(제목,내용텍스트,송신인)
라벨(Label, y)
- 맞춰야 하는 정답
예측값(y햇)
- y의 추정치 ( 모델이 내놓는 결과 )
오류
- y(데이터값)와 y햇(f값)의 차
- 앱실론(측정오차)와 다르다.
- 앱실론은 정해진 값이고 우리가 줄이고자 하는건 오류


2-1 회귀 문제
- 회귀
  - 입력으로부터 숫자를 얼마나 정확히 예측할까?
  - 라벨 및 예측모델의 출력은 연속적인 수치
- 집값 예측
  - feature : 면적,방수,연식
  - Label: 집값
- 매출액 예측
  - Feature: 매체별 광고비
  - Label: 매출액

2-2 회귀오류: 평균제곱오차(MSE):Mean Squared Error
오류의 제곱의 평균.
좋은모델이란 MSE가 작은것.
제곱이라 해석이 어렵다면? RMSE(Root) 그냥 MSE에 루트씌운것. => 그러면 실제 오류에 가깝.

2-3 회귀 설명력: R^2(결정계수)
- 결정계수(R^2)
  - Label의 분산 중에서 Feature로 설명되는 비율

3-1 분류 문제
- 분류
  - 출력이 범주값일때
  - 이진라벨(스팸/일반 , 양성/음성) or 다중라벨(학점)

3-1 분류 정확도
- MSE나 R^2을 사용하기 어렵다.
- 정확도: 정답률
  - 지시함수: 맞으면1 틀리면0
  - 정확도가 99%면 좋은 모델일까? => 양성99개양성1개인 데이터에서 "전부음성이다"라고 예측하는 모델을 실행하면 
  - 정확도는 99%이지만 좋은모델이 아님. => 즉, 다양한 데이터를 넣어봐야함.
  - 그러므로 다른 지표도 같이봐야 안전
- 혼동행렬: 예측과 실제값 사이의 관계를 행렬 형태로 표현
  - 정밀도: 양성이라고 예측한 것중에 진짜 양성의 비율
  - 재현율: 실제양성 중에서 양성이라 예측한 비율
  - F1-score: 정밀도와 재현율의 조화평균
  - 정밀도와 재현율은 클수록 좋다.

4-1 학습의 목적
- 훈련데이터에서 학습한 모델이 새로운데이터에서도 정확한 예측하는 것
- 훈련이 잘 됐는지 어떻게 확인할까? -> 새로운데이터로 평가
- 새로운 데이터에서도 성능유지 -> 일반화성능

4-2 오버피팅이란?
- 오버피팅
  - 훈련데이터의 우연한패턴/잡음까지 외워버려서, 훈련에서는 잘맞지만 테스트에서는 성능이 나빠지는 현상
  - 현상: 훈련오류급격히낮음, 테스트오류 높음/요동
  - 오버피팅이 왜 안좋은가? -> 샘플 몇개만 바뀌어도 예측이 크게 흔들림.
- 오버피팅에 대한 오해
  - 아예 다른 분포데이터를 가져와서 에러가 증가하는게 아님
  - 분포가 같은데도 에러가 증가하는현상.

## 테스트 성능 평가
- 훈련오류 vs 테스트오류
  - 훈련오류: 문제집에서 틀리는거
  - 테스트오류: 시험에서 틀리는거
  - 훈련오류는 테스트오류를 과소평가하는 경우가 많음
    - 암기 vs 응용 시험
  - 모델이 복잡해질수록 훈련오류는 계속 작아짐. 왜냐면 계속 같은패턴을 학습하니까.
  - 근데 테스트 오류는 U자형으로 증가.
- 테스트 예측 오류 계산
  - 이상적 케이스: 충분히 큰 별도 테스트 데이터셋
  - 현실: 테스트데이터를 얻기 어려움
- 대안: 재표본화를 통한 테스트 오류 추정
  - 별도의 테스트데이터 없이 훈련데이터만으로 테스트데이터의 오류를 가늠
  - 검증셋, K겹 교차검증

2-1. 검증셋 방법
- 가용 샘플들을 무작위로 훈련셋과 검증셋으로 분할
  - 문제집의 문제들을 모의고사용과 학습용으로 나누고 모의고사는 딱1번만 보기.
- 훈련셋으로 모델 적합, 검증셋으로 예측 후 검증 오류를 계산.
- 검증오류는 보통 정량 반응은 MSE, 범주반응은 오분류율(또는 F1-Score)을 사용

2-2 검증셋 절차
- 데이터 무작위 셔플링 후 두부분 분할.
- 학습은 훈련셋에서, 성능평가는 검증셋에서 수행.

2-3 검증셋 방법 예시

- K개중 1개를 선택해 검증용으로 사용 나머지는 훈련데이터로 사용.
- 이를 K번 한다.
- K개의 MSE의 평균을 낸다.
