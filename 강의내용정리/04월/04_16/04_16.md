# Django Form
- HTML Form의 한계
  - 지금까지 사용자로부터 데이터를 제출 받기위해 활용한 방법
  - 그러나 비정상적 혹은 악의적인 요청을 필터링 할 수 없음
  - 유효한 데이터인지 확인이 필요하다
- 유효성 검사
  - 수집한 데이터가 정확하고 유효한지 확인하는 과정
  - Django Form의 유효성 검사는 사용자가 입력한 데이터가 올바른 형식인지 자동으로 점검하는 기능을 제공한다.
  - 예를들어, 필수 입력 값이 비어 있거나 잘못된 이메일 형식을 입력하면 오류를 알려준다.
  - 이 과정을 통해 서버에 잘못된 데이터가 저장되지 않도록 보호할 수 있다.
- 유효성 검사 구현의 어려움
  - 유효성 검사를 구현하기 위해서는 입력 값, 형식, 중복, 범위, 보안 등 많은 것들을 고려해야 함
  - 이런 과정과 기능을 직접 개발하는 것이 아닌 Django가 제공하는 Form을 사용
- Django Form의 기능
  - 사용자 입력 데이터를 수집하고, 처리 및 유효성 검사를 수행하기 위한 도구
## Form Class
- Form Class 정의
  - Form Class를 상속받아 내용과 제목에 대한 사용자 입력을 받는 ArticleForm을 정의하는 방법
  - forms.py
  - from django import forms
  - class ArticleForm(form.Form):
  - title = forms.CharField(max_length=10)
  - content = form.CharField()
- Form Class를 적용한 new logic(1/3)
  - view 함수 new 변경
  - views.py
  - from .forms import ArticleForm
  - def new(request):
  - form = ArticleForm()
  - context = {
  - 'form' : form
  - }
  - return render(request, 'articles/new.html, context)
- Form Class를 적용한 now logic(2/3)
  - new 페이지에서 form 인스턴스 출력
  - new.html
  - form 태그 내에서 {{form}} 이라는 인스턴스 출력하기.
  - 이렇게까지 하면, 굳이 input이런거 안써도 알아서 만들어준다 이런거같음
## Widgets

- Django Form의 widgets은 각 필드가 HTML에서 어떻게 랜더링 될지를 결정한다.
- 예를들어, TextInput, Select, CheckboxInpu 등 다양한 위젯 클래스를 사용해 입력 받을 속성을 세부 조정할 수 있다.
## Django ModelForm
- Form vs ModelForm
  - Form: 사용자 입력 데이터를 DB에 저장하지 않을때(검색,로그인)
  - ModelForm: 사용자 입력 데이터를 DB에 저장해야 할 때(게시글작성,회원가입)
- ModelForm 기능
  - Model과 연결된 Form을 자동으로 생성해주는 기능을 제공
    - ModelForm은 Form 클래스와 Model클래스를 결합한 형태로, 모델 필드를 기반으로 입력 폼을 자동 생성해준다.
    - 데이터 수집과 저장 과정을 동시에 처리할 수 있도록 도와준다.
  - forms.py
  - from django import forms
  - from .models import Article
  - class ArticleForm(forms.ModelForm):
    - class Meta:
      - model = Article
      - fields = '__all__'
