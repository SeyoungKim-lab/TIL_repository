- 변수: 카멜케이스, studentName
  - let: 재할당 O, 재선언 X
  - const: 재할당 X, 재선언X [일반적으로 사용]
  - var(사용 X, 호이스팅 문제): 재할당 O, 재선언 O
        - TDZ: 최상단 선언부터 해당 변수의 초기화 지점까지의 영역 => 접근하면 에러
        - var/function(TDZ X), let, const(TDZ O)

- DOM
  - 웹을 구조화된 객체로 제공
  - 객체를 프로그래밍 언어로 이용해서 조작할 수 있다.
  - document 객체: 최상위 객체, 모든 컨텐츠의 진입점

- 동적인 웹페이지 컨트롤
  1. 선택: document.querySelector(selctor ex: "#name", ".name"), document.querySelectorAll(Selctor)
  2. 조작
     - 속성 조작
     - 클래스 조작: .classListadd(클래스), remove(), toggle()
     - 일반 속성 조작:getAttribute(), setAttribute(name, value),            removeAttribute()

     - 컨텐츠 조작: 요소.textContent
     - DOM 요소를 생성하고, 추가, 삭제
        - 노드 생성: document.createElement(tagName)
        - Node.appendChild(요소)
        - Node.removeChild(요소)
     - 스타일 조작(가급적 사용 X, 클래스 활용하자)
