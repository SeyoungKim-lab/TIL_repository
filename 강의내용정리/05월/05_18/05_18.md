# 객체 기초
## Object (=딕셔너리)
- 키로 구분된 데이터 집합을 저장하는 자료형
- Key는 문자형만 허용(파이썬은 불변이면 다 올 수 있음)
- value는 모든 자료형 허용
- 대괄호 접근 or '.' 접근

## 메서드와 this
- Method
- 일반함수는 소속이 없다, 메서드는 객체(주인)이 있다.
- this를 이용해 자신의 주인을 가리킴.

## JSON
- 일정한 형식을 가진 '문자열'

## 추가 객체 문법
1. 단축 속성
   - key, value 이름이 같은경우 단축가능
2. 단축 메서드
   - function 생략가능
3. 계산된 속성
   - 키가 대괄호로 둘러싸여 있는 속성 (변수사요가능)
4. 구조 분해 할당
7. Optional chaining
