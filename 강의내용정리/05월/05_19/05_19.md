# 복습
- 객체(Object, 파이썬의 dict)
  - key, value로 구성
  - key는 문자형만 가능하다
  - in 연산자 대신에 hasOwnProperty()를 사용할 것
- this
  - 함수나 메서드를 호출한 객체를 가리키는 키워드(파이썬:self)
  - 일반함수: 전역객체
  - 메서드: 호출한 객체
    - 메서드?? : 객체 안에서 선언된 함수
- 콜백함수
  - 다른 함수로부터 호출되는 함수
- Array Method
  - forEach
    - arr.forEach(function(item,index,array){
    - item: 현재 접근하고 있는 인자
    - index: 현재 접근 인자의 인덱스
    - array: 접근하고 있는 배열 전체
    - })
    - 단순 순회용, 반환값도 없다.
  - map
    - arr.map(똑같)
    - 원본배열을 변경하지 않고 새로운 배열을 반환. return이 필수.
    - 원본과 크기가 같은 배열이 생성된다.
  - filter
    - arr.filter(똑같)
    - return이 필수. 리턴값은 true or false. true인애들만 반환.
    - 원본과 크기가 같거나 작은 배열이 생성.
  - reduce
    - arr.reduce(function(acc,cur,index,array){
    - acc: 이전까지 누적된 값
    - cur: 현재 쳐다보고 있는 값
    - }, 초기값)
    - 배열을 완전히 다른 형태로 변환할 때 사용 (리스트 -> 숫자(합), 리스트 -> Object)

# 이벤트
## event
- 웹 페이지 상에서 '무언가 일어났다는 신호 또는 사건'
- 모든 DOM요소는 다양한 형태의 이벤트 발생시킬 수 있음
- button클릭 이벤트, input값 변경시 input 이벤트,,,
## event object
- mdn에 들어가면 여러가지 event 있음.(필요하면 그때그때 찾아쓰기)
- 클릭이라는 이벤트가 발생하면 이벤트처리기(handler)가 실행(콜백함수)
## event handler
- 특정 이벤트가 발생했을 떄 실행되는 콜백함수
- .addEventListener() : 특정 DOM요소에 지정된 이벤트가 발생했을 때 실행할 이벤트핸들러를 
- 등록하는 메서드
- button(요소).addEventListener('click'(이벤트), 콜백함수)
- 1.요소를 가져온다. 2.콜백함수 생성한다. 3.리스너 등록.
- 이떄 콜백함수는 첫번째인자로 "event"를 가짐. event는 이벤트에대한 정보를 담고있음.
- 이때 콜백함수 내의 this는 전역객체가 아닌 요소를 가리킴.

# 버블링
- 한 요소에 이벤트가 발생하면, 해당요소 핸들러가 동작한 후 이어서 부모 요소의
- 핸들러가 동작하는 현상. 가장 최상단의 조상요소 만날때까지 반복됨.
- 버블버블(거품거품)하면서 다 이어지니까 이렇게 이름지어짐.
- 이벤트가 정확히 어디서 발생했는지 접근할 수 있는 방법.
  - event.currentTarget
    - 리스너가 반응한 시점?(=this)
  - event.target
    - 사용자가 클릭한 시점?
## 캡처링과 버블링
- 캡처링: 버블링의 반대로, 최상위요소부터 아래로 전파됨
- 실제 개발자가 다루는 경우는 거의 없음.
## 버블링의 필요성

- 각 버튼마다 다른 동작을 하고싶다면 event.target을 이용해 제어
