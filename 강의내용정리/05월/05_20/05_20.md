# 비동기
## 동기
- 앞에 코드가 종료되야 뒤에코드가 실행됨.
## 비동기
- 병렬작업. 동시작업.

# JavaScript와 비동기
## Single Thread 언어, JavaScript
- JS는 한 번에 하나의 일만 수행할 수 있는 Single Thread 언어로
- 동시에 여러 작업을 처리할 수 없음.
- 근데 어떻게 비동기처리를 할 수 있을까.
## JavaScript Runtime
- Call Stack: 일 목록
- Web API : 비동기 일 처리((ex)3초기디라기)
- Tack Queue : 대기(3초끝났으면 여기로 줄서기)
- Event Loop : 안내
# Ajax
- 비동기적인 웹 애플리케이션 개발을 위한 기술
- 새로고침없이 부분적으로 랜더링
- 브라우저와 서버 간의 데이터를 비동기적으로 교환하는 기술
- JSON 형식으로 주고받는다.
- 목적
    - 비동기 통신: 새로고침x
    - 부분 업데이트: UX향상
    - 서버부하감소
