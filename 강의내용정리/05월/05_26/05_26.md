## Frontend Development
- Client-side frameworks
- SPA(Single Page Application)
  - 단일 페이지에서 동작하는 웹 애플리케이션
- SSR(Server Side Rendering)
  - 서버측에서 랜더링
- CSR(Client Side Rendering)
  - 클라이언트에서 콘텐츠를 렌더링
  - 부품만 오면 우리가 완성을 시킨다.
  - 작동원리
    - 사용자가 웹사이트에 요청을 보냄.
    - 서버는 최소한의 HTML과 JavaScript 파일을 클라이언트로 전송
    - 클라이언트는 HTML과 JavaScript를 다운로드 받음
    - 브라우저가 JavaScript를 실행하여 동적으로 페이지 콘텐츠를 생성
    - 필요한 데이터는 API를 통해 서버로부터 비동기적으로 가져옴

## ref 객체
- 일반적인 변수는 값이 바뀌면 저장만하느넫, ref객체는 값이 변경되면 변경사항을 감지함.
- 화면에 변경내용이 자동으로 업데이트 되기 원할때 사용
