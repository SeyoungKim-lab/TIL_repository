# Conditional Rendering
## v-if
- <p v-if="isSeen"> true일때 보여요</p>
- const isSeen = ref(true)
- <template> 태그는 화면에 보여지지는 않지만 if문같은거 처리할때 사용
## v-if vs v-show
- v-show
  - <div v-show="isShow">v-show</div>
  - 이건 무조건 화면에 출력하지만 false이면 style="display:none" 으로 출력
  - v-if
    - 매번 토글해야하므로 토글비용이 높음
  - v-show
    - 일단 다 렌더링하니까 초기 렌더링비용이 높음.
    - 토글비용은 낮다.
    - 콘텐츠를 매우 자주 전환해야 하는 경우에는 v-show 권장.
    - else가 없다.

# List Rendering
## v-for
- 소스 데이터를 기반으로 요소 또는 템플릿 블록을 반복 레더링
- 할 일, 상품목록 등 반복해서 화면에 표시할떄 사용
- 이때도 template 태그 자주 사용
## v-for with key
- v-for="item in items" :key="item.id"
- 각 div태그마다의 고유번호
- key는 문자열 또는 숫자
## v-for with v-if
- v-if를 우선처리함
- v-for="todo in todos" v-if="todo.isComplete" 에서 todo를 인식하지못함
- 그럼 어떡하냐
  - 1. computed 활용하여 필터링 한 후 그걸 for
  - 2. templete으로 v-for 하고, 그 내부에서 if문
  
# Watchers
## watch
- watch()
  - 반응형 데이터를 감시하고, 데이터가 변하면 콜백함수를 호출
  - watch(지켜볼반응형변수,콜백함수)
  - 콜백함수의 첫번째인자 newValue, 두번째인자 oldValue
  - 배열로 받을 수도 있다.
## computed vs watch
- 공통점: 데이터변화를 감지하고 처리
- computed는 반드시 반환값, watch는 그렇지않음.
